# 💻 Desenvolvimento de Sites

Este repositório reúne projetos de desenvolvimento web com HTML, CSS e JavaScript. Aqui você vai encontrar landing pages, portfolios, mini projetos, formulários e outros exercícios de front-end.

## Objetivo

O objetivo deste repositório é:
- praticar e melhorar habilidades em HTML, CSS e JavaScript;
- organizar projetos web em pastas separadas;
- criar um portfólio visual com trabalhos reais;
- registrar ideias e projetos em evolução.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub Pages
